## 0. 這版怎麼想的（給你看，不上網站）

**讀的人是誰**：一個在台灣做品牌的老闆，手機上滑到這個網站。可能被貿易商坑過、可能拿過一份 80 頁報告、可能只是聽朋友說菲律賓有機會。他不想被推銷，他想知道「這些人懂不懂我會遇到什麼」。

**整個首頁是一條故事線**：
1. Hero（你原本的）：先讓他知道我們做什麼。
2. 「貨到了之後」：一個他認得的場景——貨送到了，然後呢。
3. 四方案＝「一家品牌在馬尼拉的第一年」：四張卡是四個章節，第一個月、第三個月、第九個月、之後的每一天。
4. 躍馬＝「四十二年，看著貨櫃出去」：為什麼是我們，用觀察講，不用頭銜講。
5. 案例＝「三條路」：顧問說的三種成功案例，講成三個短故事。
6. 一份合約＝「星期一到星期四」：老闆當中央窗口的一週。
7. FAQ＝桌邊對話。
8. CTA：你原本的標題，換一句副標。

**顧問的信仰怎麼放**：
- 「台灣市場不夠大」→ 放在躍馬段的「我們相信的事」，講成大家都知道的常識，不是警告。
- 「解決最難的事」→ 每一章的場景就是那件最難的事，不用寫出「最難」兩個字。
- 「不是賭夢想，是有做過」→ 案例區標題，原句。
- 「有立場」→「有時候我們會建議你再等等」，每頁一次。
- 「不做貿易商」→ about 的邊界，語氣是說明不是劃線。

**故事的規矩**：場景都是「常見的版本」，不寫成真實客戶、不給名字、不給數字。真實案例只有三條路和四篇個案卡。

## 13. about 頁（三段）

**創辦故事（#story）**
```
我在躍馬企業看了很多年。

躍馬做的是把貨送出去——42 年，500 多個出口案件，30 多個國家。
我在裡面看的不是報表，是貨櫃出去以後的事。
有的品牌在當地開了第二家店。
更多的是幾個月後貨退回來，或者就沒有下文了。

我後來想通一件事：差別從來不在物流，貨都有送到。
差別在到了之後，有沒有人接著走。
證有沒有人辦、架上有沒有人推、第一封英文客訴信有沒有人回。

台灣市場不夠大，這件事做生意的人都知道。出去有難度，但出得去。
鹿飛做的，是把貨到了之後最難的四件事做成四個方案，
讓第一步小到你敢踏，後面的每一步都有人在。
```

**品牌理念（#philosophy）**
```
我們相信的事

一、台灣市場不夠大，出去是遲早的事。早一點、小一點開始，比晚一點、大一點便宜。
二、先做最難的那一件。辦證、開公司、接客訴——最難的我們先做；做不到的，我們老實說。
三、有立場。兩個選擇都對的時候，我們會建議能讓你長大的那一個，不是省事的那一個。
四、我們不是跟你賭夢想，是有做過的事。
```

**我們不做什麼（#what-we-dont-do）**
```
誠實的邊界

・我們不當貿易商。不買你的貨、不扛你的業績，我們把賣出去的路打通，貨還是你的。
・我們不當純接單的貨代。物流是躍馬 42 年的底，但鹿飛賣的不是運費。
・我們不接「放貨給你賣、賣掉再抽成」的合作。這種模式通常對雙方都不划算，我們會第一次談就說。
・我們不保證合規、不保證進通路。證幫你申請、坑幫你避，責任在品牌方；通路幫你談，賣不賣得動，品測會先告訴你。
```
