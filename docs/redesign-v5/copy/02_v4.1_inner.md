## 0. 三個貫穿全站的設計決定

### 0.1 章節列（Chapter bar）
四個菲律賓方案頁的 hero 下方，放一條橫向的章節列，永遠顯示四章、標出現在在哪一章：

```
第一個月 品測  ●──────  第三個月 寄賣  ○──────  第九個月 公司落地  ○──────  之後的每一天 海外客服  ○
```

設計：手機上可橫向捲動；目前頁的節點填色、字加粗；其他節點可點。這一條讓讀者不管從哪一頁進來，都知道自己在故事的哪裡、前後是什麼。北美通路頁不放這條，改放一行「這是另一個故事」。

### 0.2 每頁結尾的「下一章」
四個方案頁的 CTA 之前，放一張小卡：

```
下一章 →
第三個月 · 寄賣
上架了，讓人先用過再說
```

設計：跟章節列連動；最後一章（海外客服）的下一章改成「回到第一章：先做品測」或「看三條路」。這是故事的翻頁感。

### 0.3 延伸閱讀（部落格進內頁的方式）
每個方案頁在 FAQ 之後、下一章之前，放 2～3 篇對應分類的文章卡。這就是部落格在網站裡的位置：**不是一個獨立要人去逛的角落，是每一章讀到一半想深入時，旁邊剛好有一篇。** 詳細見第 3.2 節。

設計：沿用現在首頁「最新文章」的卡片元件（標題＋日期＋閱讀分鐘），三張一列，手機一列一張。

## 1.1 品測（/services/product-testing）

**這一頁要做到的事**：讓一個猶豫的人覺得「1～2 萬、一頁報告、沒過就停」——這個門檻低到不試對不起自己。全頁最重要的一句是「沒過，故事在這裡停」。

### 段 1 Hero
設計：現有子頁 hero 版型，背景圖換成「一桌人圍著產品」的畫面（真實面板照片最好；沒有就用當地學校或教室的環境照，不要用 stock 的握手圖）。
```
第一個月 · 品測
先讓馬尼拉的媽媽拿起來看看

你在台灣問了一百個人，還是不知道馬尼拉的媽媽會不會掏錢。
品測就是把這個問題，拿去問她本人。

[聊聊你的產品 →]   [先做 2 分鐘處境比對]
```

### 段 2 章節列
見 0.1，目前在「第一個月」。

### 段 3 這一章常見的開頭
設計：三張並排的小卡（手機直排），每張一句話，不加圖示。標題用「你可能是這樣走到這裡的」。
```
你可能是這樣走到這裡的

・有產品，聽說東南亞有機會，但不知道從哪裡開始。
・找過顧問，拿到一份很厚的報告，還是不知道該不該去。
・怕一去就是幾百萬，想先花小錢確認。
```

### 段 4 品測那一天會發生什麼
設計：這是本頁的核心，用「時間軸」元件（現有 localization 頁如果有步驟元件就沿用，沒有就用四張橫排卡）。每一步是一個畫面，不是功能名稱。
```
品測那一天會發生什麼

01 你寄三支產品到馬尼拉
　 我們先幫你看：這三支在當地有沒有類似的、賣多少錢。

02 一桌老師和家長
　 當地學校的老師（高收入的工薪階層）和家長（真正掏錢的人）圍著桌子。
　 拿起來、聞一聞、翻價錢。有人皺眉，有人問哪裡買得到。

03 我們在旁邊記
　 誰拿了第二次、誰看到價錢放下、誰問了成分。每一支產品至少六個數據來源。

04 一頁報告
　 誰會買、多少錢會買、為什麼不買，附台菲兩地的價差對比。
　 面板跑完就給，不用等產品證。
```

### 段 5 你會拿到什麼
設計：一張「報告長相」的示意卡。左邊是一頁報告的縮圖（可以用真的模板去識別化，或畫一個線框），右邊三行說明。
```
你會拿到一頁，不是八十頁

・誰會買：哪一群人拿了第二次
・多少錢會買：價格帶落在哪、跟台灣差多少

這一頁是拿來做下一個決定的，不是拿來歸檔的。
```

```
過了 → 這筆抵進第三個月的寄賣包（5～6 萬），合起來就是 7 萬起手包。
```

## 1.2 寄賣（/services/consignment，新頁）

**這一頁要做到的事**：讓人理解寄賣包不是「幫你上傳商品」，是證還沒下來那 6～12 週怎麼不浪費、上了架怎麼有人推。最重要的一句是「證下來那天，架上已經有人在等」。

## 1.3 公司落地（/services/localization，改寫）

**這一頁要做到的事**：這是能力的天花板，多數人不會買，但要讓人知道「走到這一章，這些人接得住」。所以這頁的重心不是價格，是「三條路」和「每一件事都要有人在當地」。

### 段 1 Hero
設計：背景用當地辦公室或店面開幕的實景（合作夥伴的教育機構或手搖飲店，去識別化）。
```
第九個月 · 公司落地
開始想要在當地有自己的人

賣得動了。你開始想：要不要開一間自己的公司、找第一個員工、把證掛到自己名下。
然後你發現，每一件事都需要有人在當地。

[聊聊你想在菲律賓開什麼 →]
```

### 段 2 章節列（在「第九個月」）

### 段 3 你可能是這樣走到這裡的
```
・寄賣或代理跑順了，想在當地設點，不知道從註冊到招聘要花多少、多久。
・連鎖餐飲、美業品牌，想開第一家店，怕被拿走配方、怕選錯區。
・在台灣有團隊，想在菲律賓聘人遠程做，不知道怎麼合規。
```

### 段 4 落地要處理的事，跟誰在處理
設計：兩欄表。左欄「要處理的事」，右欄「誰在當地」。目的是把「每一件都要有人在當地」具象化。
```
落地的每一件事，都要有人在當地

要處理的事　　　　　　　　誰在當地
公司註冊、律師行文件　　　合作的律師行，我們對窗口
招聘：實體或遠程團隊　　　合作夥伴的 HR 體系，面試、到職、第一批人的訓練
FDA 掛證與合規　　　　　　持證進口商＋律師行，我們統籌
場地、設備、日常營運　　　合作夥伴的營運團隊，第一批人到位、流程跑順
你的角色　　　　　　　　　做決定、看進度。不用一直飛。
```

### 段 5 我們走過的三條路
設計：三張直卡（手機直排），每張一個小標、三到四行故事、一行「適合誰」。這一段是本頁的靈魂，也是顧問說的「三種成功案例」。
```
我們跟合作夥伴走過的三條路

第一條　從零開始
在當地蓋一間英語教育機構——找老師、找場地、招第一個學生。
後來用同樣的方法，做了一個連鎖手搖飲品牌。
適合：要在當地從頭建團隊、開店的品牌。

第二條　改了再帶過去
台灣的產品到了當地，改配方、改價格、改包裝，
變成當地人願意掏錢的樣子。
適合：產品好、但知道當地口味和價格帶不一樣的品牌。

第三條　原封不動帶過去
一個台灣的美業品牌，什麼都不改，只做當地的行銷，看它站不站得住。
適合：品牌本身就是賣點、不想動產品的。

三條路的成本、坑、時間都不一樣。第一次談，我們會先問你比較像哪一條。
```

## 1.4 海外客服（/services/call-center，新頁）

**這一頁要做到的事**：讓人意識到「做海外生意一定會有客服這件事」，而且這是四個方案裡唯一不用先去菲律賓也用得到的。最重要的一句是「你不會想為了這件事養一組人，但也不能不回」。現在是登記期，不是購買期，頁面語氣要像預告，不像產品頁。

### 段 1 Hero
設計：背景用夜間的辦公室或客服桌面實景，色調偏暗。hero 上加一個小標籤「2027 Q1 首批・登記中」。
```
之後的每一天 · 海外客服
星期五晚上十一點的那封信

一封英文客訴信。退貨、換貨、問哪裡有賣。
你不會想為了這件事養一組人，但也不能不回。

[登記首批 →]
```

### 段 2 章節列（在「之後的每一天」）

### 段 3 你可能是這樣走到這裡的
```
・貨在海外賣，客訴和退換貨的訊息回不了，或回得很慢。
・去北美賣，請不起北美客服；去東南亞賣，自己人英文不夠。
・找過台灣的客服外包，價格不便宜。
```

### 段 4 一封信進來之後
設計：時間軸，四步。目的是讓人看到「規則在台灣、人在菲律賓」怎麼運作。
```
一封信進來之後

01 進到同一個信箱
　 你的客服信箱、平台訊息、社群私訊，接到同一個工作台。

02 老師等級的人接
　 一群受過完整訓練、英文老師等級的菲律賓客服團隊。
　 合作夥伴在當地經營英語教育機構與連鎖餐飲，客服來自老師體系，已經服務過家長和餐飲客戶。

03 照你的規則回
　 回覆範本、退換貨規則、什麼情況要升級給你——這些寫在服務流程裡，由鹿飛台灣公司負責。

04 你看得到
　 每月的量、回覆時間、升級次數，一份報表。
```

### 段 5 為什麼是菲律賓、為什麼是老師
```
為什麼是菲律賓、為什麼是老師

菲律賓是全世界做英文客服最成熟的地方，不是我們發明的。
我們多做的一件事，是人從老師體系來——能教家長的人，能接你的客戶。
規則、合約、品質指標留在台灣公司；人在菲律賓。你面對的窗口是我們，不是當地的廠。
```
