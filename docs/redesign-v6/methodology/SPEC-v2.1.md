## 2. 我們的初心
```
我們在物流那一端看過太多次這個順序：

先花幾百萬做行銷，找當地網紅，開始賣。
賣了一季，市場才告訴你：
價格太高、味道不對、他們聽不懂你在講什麼。
然後回頭改產品。業績平平，或者賠錢。

那幾百萬買到的，其實是一堂課。
我們想做的，是把這堂課的學費，從幾百萬降到一兩萬——
在你花大錢之前，先替你去問市場。

然後不是交一份報告就走。
問到的答案，我們跟你一起看、一起改、再問一次。
這是我們說的陪跑。
```

## 3. 我們怎麼問市場
設計：兩張大卡。桌機並排或上下；手機改成可左右滑的兩頁，底下有兩個小圓點。每張卡三個小標：我們做了什麼／問到了什麼／那又怎樣。

### 例子一
```
一盒台灣手工花生糖禮盒，想去菲律賓

我們做了什麼
請五位二十多歲的菲律賓女老師，拿著產品卡、現場試吃，一對一聊。
同時把當地花生甜食的十個競品攤開：碧瑤的老牌、超市裡的國民零食、
台灣進口的牛軋糖、在地的精品禮盒——價格、訴求、好評負評、賣在哪，一張橫表。

問到了什麼
・價格：台灣零售價換算過去，是她們心理價位的兩倍以上。
　有一位用自己一天的工資來比。
・效期：當地最有名的花生脆糖效期大約一個月；這盒長得多。
　在熱帶濕氣下，這件事比我們想的重要。
・口味：其中一個口味年輕人喜歡，長輩明確不愛。評價兩極。
・空白：十個競品裡，沒有一個主打全素和潔淨標章。這格是空的。

那又怎樣
五個人不是統計，是方向。方向對了，再花錢擴樣。
報告寫得很清楚：這是一個「定位假設」，不是已驗證的定位。
它告訴品牌三件事——價格要重想、送禮是唯一能撐住高價的場景、全素是沒人站的位置。
接下來才是品牌要不要調、怎麼調、調完再測。
```

### 例子二
```
一瓶台灣防曬，問當地的小資族

我們做了什麼
把產品拿給菲律賓的小資上班族試用，一個一個問。

問到了什麼
・她們對「維他命 C」的認知是美白。你在台灣講抗氧化，她們聽到的是另一件事。
・她們要產品有味道。台灣消費者偏好無香，菲律賓剛好相反。

那又怎樣
這兩件事，品牌在台灣問一百個人也問不到。
我們拿回來交叉驗證：對照當地的電商評價、競品怎麼寫、社群怎麼聊。
確認之後，品牌要改的不是配方，是溝通方式和香味——
而且要在當地法規允許的宣稱範圍內。這比重做產品便宜太多。
```

## 4. 你會拿到什麼
設計：兩欄；手機上下。
```
第一個月，你拿到一頁
誰會買、多少錢會買、為什麼不買。
拿來做下一個決定的，不是拿來歸檔的。

走到第三個月那一章時，有一份完整的市場研究
我們實際交出去的報告長這樣：
0 研究前提　1 競品名單　2 素材收集　3 橫表對照
4 差異切入口　5 相對優勢　6 進入挑戰　7 研究結論

每一份都寫清楚：樣本是誰、哪些是一手訪談、哪些是公開資料、信心度多高。
報告的最後一句永遠是同一句——
「本報告為決策的事實基礎，而非決策本身。」
```

## 5. 量尺：五個問題，打兩次分
```
第一次談，我們會用五個問題把你的案子粗跑一遍。
這五題有紅線，碰到就先停下來講清楚。
```
設計：五張卡做成手風琴，預設只展開第一張。無權重欄。
```
Market 市場
「這個市場夠大嗎？」
看：可觸達的市場規模、成長率、消費者願意付多少、市場在哪個階段。
紅線：可觸達市場不到你預估年營收的 20 倍，建議換市場。

Barrier 門檻
「進去要花多少力氣？」
看：認證要求與成本、通路進入難度、在地化改造（包裝、配方、標示）、合規灰色地帶。
紅線：合規認證成本超過首年毛利的一半，不建議進。

Competition 競爭
「你打得過嗎？」
看：前十大品牌市佔集中度、競品護城河、競品弱點、會不會打價格戰。
紅線：前三名市佔加起來超過 70%，不做正面競爭。

Profitability 獲利
「做得動嗎？」
看：到岸成本（FOB＋關稅＋物流＋保險）、通路佣金與行銷攤提、退換貨預估、匯率風險。
紅線：悲觀情境淨利率低於 5%，先調結構再談。

Regulatory 法規
「法規會不會突然變？」
看：當地貿易政策穩定度、產品類別法規變動歷史、政治風險、退出成本。
紅線：過去三年曾被禁或大幅加稅，風險加權。
```
設計：決策矩陣維持展開。
```
分數怎麼讀

≥ 75　Go　　　　　　可以進，照四章走。
60–74　Conditional Go　可以進，先解決一到兩個弱項。
45–59　Hold　　　　　建議暫緩 6–12 個月，等關鍵變化。
< 45　No-Go　　　　　不建議。我們會寫清楚什麼條件改了可以再看。
```
```
打兩次分

第一次是紙上分數。
用公開數據、你給的成本、我們在當地的經驗打的。
它告訴你：該不該試。

第二次是真實分數。
品測跑完，Market 和 Competition 兩題用那一桌人的反應重打一次。
它告訴你：該不該加碼。

花生糖那一案，紙上看對手是台灣進口的牛軋糖；
五位老師聊完，Competition 這題的答案變了——
真正的對手，是她們心裡那個價位。

大多數的評估停在第一次。
我們把第二次寫進流程，因為紙上的 80 分，不如一桌人裡有六個人問哪裡買。
```

## 6. 我們的規矩
設計：獨立色塊、大字級。
```
我們的規矩

總分不到 60，我們不接。
不是不想賺，是接了對你沒有好處，對我們的案例也沒有好處。

碰到任何一條紅線，我們會先說，再談要不要繼續。

有時候我們會建議你再等等。
那也是一種答案，而且是不收費的那種。

如果你想要的是先賣再說，我們可能不是對的夥伴。
```

## 7. 陪跑是什麼意思
```
報告交出去，不是結束。

品測之後，我們跟你一起看那一頁：
哪一句話要改、哪個價格帶要重想、哪個口味先不帶過去。
改完，再問一次。

通路之後，每個月看數字：賣動了什麼、沒賣動什麼、為什麼。
落地之後，人到位了、流程順了，你才不用一直飛。

每一案的真實分數，都回到同一套量尺。做得越多，量尺越準。

每一章結束，你都可以停。
但只要你往下走，我們就在。
```

## 8. 這套方法站在誰的肩膀上
```
我們沒有發明這些。

「了解多一分，才投入多一分」來自國際化研究裡被引用最多的模型¹：
企業走向海外是漸進的，先出口、再找代理、再設點，投入跟著了解走。

「用最小的錢先問市場」來自精實創業²：
最小成本換真實學習，再決定加碼。

「每一章都有閘門」來自新產品開發的階段管理³：
過了這一關，才投下一筆。

我們做的，是把這三件事壓成一個台灣中小品牌負擔得起、三個月跑得完一輪的版本。
```
頁尾註腳（小字）：`¹ Uppsala 國際化模型（Johanson & Vahlne, 1977）　² Lean Startup（Ries, 2011）　³ Stage-Gate（Cooper）`

## 9. 邊界
```
這套方法現在只做一件事：消費品牌進菲律賓。
工業設備、大型 B2B 製造、設廠，不在這裡。
北美通路是另一條線，由北美團隊執行。
海外客服不在五題裡——它不是「該不該去」的問題，是「去了之後」的問題。

一手訪談的樣本都不大，而且集中在特定族群。
我們在每一份報告裡都寫明這件事，因為它決定了你該把這份答案當多重。
```
