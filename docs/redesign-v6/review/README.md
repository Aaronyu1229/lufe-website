# 網站快照與備註工具

請 Claude 在專案最上層執行這一行，再在瀏覽器開啟畫面顯示的網址：

```bash
bash docs/redesign-v6/review/snapshot.sh && python3 docs/redesign-v6/review/serve.py
```

右下角按「備註模式：開」後，點選想討論的地方，寫下備註並按「儲存」。

「只改這一塊」是只調整點到的內容；「這一塊和周圍」是連同相鄰內容一起調整；「整個區段」是調整該標題下的整段內容。可同時選多個分類。

備註會存到 `docs/redesign-v6/review/notes.json`，Claude 可以讀取它來修改正式網站。右下角的「手機寬度看」會用手機大小預覽目前頁面；「這頁看完了」可標記已檢查的頁面。

這個工具顯示的是建立時的網站凍結副本。表單與其他送出動作不會真的傳送資料。
