## 0. 第二輪新增的全站規則（服務頁範圍）

- **R-1 服務頁不放數字統計列**（#2）：`/services` 與所有服務子頁不出現「4 個章節／42+／500+／30+」這類數字列，也不加 `data-lufe-counter`。價格（1～2 萬、5～6 萬…）不是統計，照留。
- **R-2「老師」用詞**（#10、#12）：
  - 用來形容**客服人員素質**的「老師」一律刪除，改用「專業英語客服團隊」「出身英語教育體系」。
  - 指**市場探查面板的受訪者**（當地學校教師）時，產品頁改成正式用語「教師」。
  - `/services/methodology` 是 Aaron 親寫的 v2.1 稿（「女老師」「五位老師」），**一字不動**，列入 §E 請 Aaron 決定。
  - `落地` 頁與首頁案例區的「找老師」改「招募師資」。
- **R-3 標題不用你／我／口語句**（第一輪 C-1 延伸，#11）：本輪改到的服務頁區塊標題一律改成專業標題（見 §B-2）。內文可以保留「你」。
- **R-4 FAQ 全服務頁統一成首頁樣式**（#6、#14）：左側 sticky 標題＋「還有其他問題？直接問鹿飛 →」，右側大題號手風琴、金色重點句（takeaway）、＋ 旋轉成 ×。由共用元件 `FaqSection` 提供，首頁也改用同一個元件（外觀不變）。每題都補一句 takeaway（§B-5）。
- **R-5 章節頁共用模板**（#17、#18、#19、#25、#26）：以海外客服頁為範本，市場探查、寄賣、公司落地、北美四頁一律套用：情境改成圖文交錯列、流程步驟加 icon 與動效、章節列加互動、FAQ 統一、下一章卡片加圖。規格見 §C。
- **R-6 躍馬企業**：服務總覽頁不再用躍馬當主角（#5）。躍馬只留在 FAQ 第 3 題答案裡當背景事實。
