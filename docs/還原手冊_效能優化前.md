### 路徑 B｜根治（程式碼真的退回去）— git revert

適用：確定不要這些改動了。

```bash
cd /Users/aaron/dev/lufe-website
git checkout main && git pull

# 看優化之後多了哪些 commit
git log --oneline stable-2026-09-11-before-perf..HEAD

# 開一條還原分支，把不要的 commit 逐一 revert（由新到舊）
git checkout -b revert/perf-changes
git revert --no-edit <最新那個sha> <次新的sha> ...

# 開 PR、合併，Vercel 會自動重新部署
git push -u origin revert/perf-changes
gh pr create --base main --title "revert: 退回效能優化前的狀態"
```

⛔ 不要用 `git reset --hard` + 強制推送 main。
會毀掉別人的紀錄，而且 `stable-2026-09-11-before-perf` 這個標籤已經釘住那個狀態了，不需要冒這個險。

### 路徑 C｜只還原素材檔（圖片 / 影片）

適用：程式碼想留著，但覺得壓過的圖片或影片品質不行。

**方法 1 — 從 git 標籤取回（已實測，11 個檔案校驗碼全部相符）**

```bash
cd /Users/aaron/dev/lufe-website
git checkout stable-2026-09-11-before-perf -- public/images/hero public/videos/hero

# ⚠️ 上面這行會「順便把檔案放進暫存區」，不是單純還原工作目錄。
#    收尾一定要確認狀態，不要只用肉眼比對檔案：
git status --porcelain        # 看清楚有哪些被 staged
```

**方法 2 — 從獨立備份資料夾取回（不依賴 git）**

```bash
B=/Users/aaron/dev/_lufe-backup-2026-09-11
cp -a $B/images-hero-original/. /Users/aaron/dev/lufe-website/public/images/hero/
cp -a $B/videos-hero-original/. /Users/aaron/dev/lufe-website/public/videos/hero/
```

**還原後一定要驗校驗碼**（不要只看「檔案有回來」）：

```bash
cd /Users/aaron/dev/lufe-website
B=/Users/aaron/dev/_lufe-backup-2026-09-11
while read -r name sum; do
  f=$(find public/images/hero public/videos/hero -name "$name" | head -1)
  if [ "$(md5 -q "$f")" = "$sum" ]; then echo "✅ $name"; else echo "❌ $name 不符"; fi
done < <(paste <(find $B/images-hero-original $B/videos-hero-original -type f | sed 's|.*/||') $B/checksums.txt)
```
